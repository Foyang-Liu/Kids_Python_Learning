## Day 29：列表方法进阶（1）—— sort / reverse / insert / remove

**学习目标**：掌握对列表排序、反转、插入、删除的常用方法，并理解它们在真实软件里是怎么被用到的

**讲解要点**

- **`list.sort()`**：把列表按从小到大重新排列，直接修改原列表本身（没有返回值）。加上参数 `reverse=True` 就变成从大到小排序。
  **实际场景**：手机通讯录会按姓名字母/拼音自动排序；游戏结束后把所有玩家的分数从高到低排序，生成排行榜；购物网站把商品按价格从低到高排序，方便比价。

- **`list.reverse()`**：把列表现有的顺序原地颠倒过来（注意这不是排序，只是把顺序"倒过来"）。
  **实际场景**：如果聊天记录是按时间从早到晚存储的，想让最新的消息显示在最上面，就可以用 `reverse()`；浏览器历史记录、朋友圈动态默认也是"最新的在前面"，背后常是类似的处理逻辑。

- **`list.insert(位置, 值)`**：在列表指定位置插入一个新元素，后面的元素会自动往后挪一位。
  **实际场景**：排队时有人被允许"插队"到某个位置；写"待办事项"清单时突然来了一件很紧急的事，需要插到最前面而不是加到最后；游戏背包在指定格子里放入新获得的道具。

- **`list.remove(值)`**：从列表中删除第一个"等于这个值"的元素（如果这个值不存在，程序会报错）。
  **实际场景**：网购时把购物车里的某件商品删掉；通讯录里删除一个不再联系的人；游戏里用掉或丢弃某个道具后，把它从背包列表中移除。

**练习题**
1. 定义一个乱序的数字列表（如 `[5, 2, 8, 1, 9]`），用 `sort()` 升序排序后打印，再用 `sort(reverse=True)` 降序排序后打印
2. 定义一个水果列表 `["苹果", "香蕉", "橙子"]`，用 `insert()` 在开头插入"葡萄"，用 `remove()` 删除"香蕉"，每一步都打印列表看变化
3. 挑战：模拟一个简单的"任务清单"——初始任务列表里有3个任务，用 `insert()` 插入一个"紧急任务"到最前面，完成后用 `remove()` 移除一个已完成的任务，每一步都打印当前列表

## Day 30：列表方法进阶（2）—— pop / index / count，以及列表复制的陷阱

**学习目标**：掌握 `pop()`、`index()`、`count()` 的用法；理解直接赋值和复制列表的区别，避开新手最容易踩的坑

**讲解要点**

- **`list.pop()`**：删除并"返回"列表的最后一个元素（也可以指定位置，如 `pop(0)` 删除并返回第一个）。和 `remove()` 的区别是：`pop()` 按"位置"删，`remove()` 按"值"删；而且 `pop()` 会把删掉的元素返回给你，方便接着使用。
  **实际场景**：很多软件的"撤销"功能，就是把最后一步操作从历史记录列表里 `pop` 出来，恢复到上一步的状态；抽奖箱、叫号系统从末尾取出一个号码进行处理，也是同样的思路。

- **`list.index(值)`**：查找某个值在列表中第一次出现的位置（下标），如果这个值不存在会报错。
  **实际场景**：先在通讯录列表里找到某个联系人的位置，再对这个位置的信息进行编辑；游戏里查找某个道具在背包里排第几位，方便展示或使用它。

- **`list.count(值)`**：统计某个值在列表中一共出现了多少次。
  **实际场景**：统计全班成绩单里某个具体分数出现了几次；统计一局游戏里某种道具一共掉落了多少个；统计投票结果里某个选项被选了多少次。

- **列表复制的陷阱：`b = a` 和 `b = a.copy()` 的区别**：`b = a` 并不是复制出一份新列表，而是让 `b` 和 `a` 成为同一个列表的两个"名字"，改动 `b` 会直接影响 `a`；只有用 `a.copy()`（或 `a[:]`）才是真正复制出一份独立的新列表。
  **实际场景**：这是新手写游戏存档、多人共享数据时最容易踩的坑——比如以为把"存档1"复制成了"存档2"，结果修改存档2时存档1也跟着变了；或者小组作业时以为复制了一份名单单独修改，结果原始名单也被意外改动了。

**练习题**
1. 定义列表 `[10, 20, 30, 40]`，用 `pop()` 删除并打印最后一个元素，再打印剩下的列表
2. 定义列表 `["a", "b", "c", "b", "a"]`，用 `index("b")` 查找"b"第一次出现的位置，用 `count("a")` 统计"a"出现的次数
3. 挑战：验证"陷阱"——定义 `a = [1, 2, 3]`，让 `b = a`，修改b（比如 `b.append(4)`），打印a看看有没有被影响；然后用 `c = a.copy()` 重新试一次，验证c的改变这次不会影响a

## Day 31：元组（tuple）基础

**学习目标**：理解元组和列表的相似与不同，掌握元组的创建与访问，明白"不可变"在实际项目里意味着什么

**讲解要点**

- **元组用 `()` 创建，如 `point = (3, 5)`**，和列表一样可以用索引、切片、`len()` 访问其中的内容。
  **实际场景**：地图上一个格子的坐标 `(x, y)`；一个像素点的RGB颜色 `(255, 0, 0)`；一条学生记录里绑在一起、不会被拆开单独使用的信息组合，比如 `(学号, 姓名)`。

- **元组一旦创建就不能被修改（不可变）**，如果尝试给某个位置重新赋值会直接报错。
  **实际场景**：游戏地图里"出生点"的坐标一旦设定好，程序运行过程中不应该被意外改动，用元组可以从代码层面"锁死"这个数据，防止不小心改错；类似的还有身份证号、日期这类"事实上不该被程序中途修改"的数据。

**练习题**
1. 定义一个表示坐标的元组 `point = (3, 5)`，分别打印x坐标和y坐标
2. 尝试修改元组里的一个元素（比如 `point[0] = 10`），观察报错信息，理解元组"不可变"的含义
3. 挑战：定义一个装有5个RGB颜色元组的列表（比如 `[(255,0,0), (0,255,0), ...]`），用for循环遍历打印每个颜色的R、G、B值

## Day 32：元组与列表对比、元组解包

**学习目标**：掌握元组解包的写法，理解函数如何"一次返回多个值"，以及什么时候该用元组、什么时候该用列表

**讲解要点**

- **元组解包：`x, y = point`**，可以直接把元组"拆开"，依次赋值给多个变量，写法比用 `point[0]`、`point[1]` 更直观。
  **实际场景**：游戏引擎处理鼠标点击时，经常会返回一个 `(x, y)` 坐标元组，用解包一次性拿到两个坐标值直接使用；地图应用返回的经纬度 `(纬度, 经度)` 也是类似用法。

- **函数可以用元组"一次返回多个值"**，比如 `return min_val, max_val`，调用时直接用多个变量接收结果。
  **实际场景**：写一个"体检报告分析"函数，同时返回身高、体重两个结果；写一个"游戏结算"函数，同时返回本局获得的金币数和经验值，不用为了返回两个数据专门写两个函数。

- **什么时候用元组、什么时候用列表**：元组适合"一组固定不变、绑在一起使用"的数据（坐标、颜色）；列表适合"会不断增删改的数据集合"（背包里的道具、班级学生名单）。

**练习题**
1. 定义 `point = (3, 5)`，用解包写法 `x, y = point`，分别打印x和y
2. 写一个函数 `get_min_max(nums)`，同时返回列表中的最小值和最大值，调用它并用两个变量接收结果
3. 挑战：写一个函数 `get_name_age()`，返回一个包含姓名和年龄的元组，调用它并用解包方式接收，打印"我叫XX，今年XX岁"

## Day 33：集合（set）基础

**学习目标**：理解集合"自动去重、无序"的特点，掌握基本操作，知道这个特性在真实场景里能解决什么问题

**讲解要点**

- **集合用 `{}` 创建，如 `s = {1, 2, 3}`**（空集合不能写 `{}`，那是空字典，要写 `set()`）。集合最大的特点是**自动去掉重复元素**，而且是**无序的**（不能像列表一样用索引访问某个位置）。
  **实际场景**：统计一天内网站一共有多少个"不同"用户访问过（同一个人访问10次也只算1个）；收集全班同学喜欢的运动项目，看看一共有多少种"不同"的运动被提到过，而不用管谁先说的谁后说的。

- **`add()` 添加元素，`remove()` 删除元素**。
  **实际场景**："已读文章"记录——每读一篇就把文章ID加进集合里，因为不需要关心顺序，也不希望同一篇文章被重复记录；游戏里"已解锁成就"的集合，玩家再次达成同一个成就也不会重复记录一次。

**练习题**
1. 定义一个包含重复数字的列表 `[1, 2, 2, 3, 3, 3, 4]`，用 `set()` 把它转成集合，打印结果，观察重复的数字去哪了
2. 创建一个空集合，用 `add()` 依次加入5个喜欢的数字（其中故意加入1-2个重复的），打印最终集合，看看一共有多少个元素
3. 挑战：写一个程序，输入一句话，用 `set()` 把它按字符拆开，统计这句话里一共用了多少种不同的字符

## Day 34：集合运算与综合练习

**学习目标**：掌握交集、并集、差集运算，理解它们分别对应哪类实际问题，综合运用本周所学

**讲解要点**

- **交集 `&`：两个集合共同拥有的元素**。
  **实际场景**：找出"我喜欢的游戏"和"朋友喜欢的游戏"两个集合里"你们都喜欢"的那些游戏，方便约着一起玩；找两个班级学生名单里"两边都报名了"的重复报名学生。

- **并集 `|`：两个集合所有的元素（自动去重）**。
  **实际场景**：把两个班级的学生名单合并成一份"年级活动参与名单"，同一个学生哪怕两边名单都有也只算一次；把两轮收集到的"同学意见反馈"合并成一份不重复的清单。

- **差集 `-`：在第一个集合里、但不在第二个集合里的元素**。
  **实际场景**：全班学生名单减去"今天请假"的学生名单，剩下的就是"今天到校"的学生；游戏里"所有关卡"集合减去"已通关的关卡"集合，剩下的就是"还没玩过的关卡"。

**练习题**
1. 定义两个集合 `set1 = {1,2,3,4,5}`、`set2 = {4,5,6,7,8}`，分别计算并打印它们的交集、并集、差集
2. 定义"我喜欢的水果"和"朋友喜欢的水果"两个集合，用交集运算找出"你们都喜欢的水果"
3. 挑战：综合运用本周所学——定义一个有重复数字的列表，先用 `set()` 去重后转回列表，再用 `sort()` 排序，最后打印"去重排序后的结果"（这就是明天Checkpoint要做的核心逻辑，可以提前熟悉一下）
